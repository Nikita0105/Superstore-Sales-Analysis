Project Overview

This project presents an interactive Sales Analysis Dashboard built using Power BI, based on the Superstore dataset. The dashboard provides insights into sales performance, profit trends, customer behavior, regional performance, and product category analysis.

The main objective of this project is to:

Analyze overall sales and profit performance

Identify top-performing products and regions

Detect loss-making categories

Track customer purchasing behavior

Provide actionable business insights using data visualization

This project demonstrates my skills in Data Cleaning, Data Modeling, DAX, Data Visualization, and Business Insights Generation.
